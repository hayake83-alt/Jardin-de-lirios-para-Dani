# Campo de lirios para Dani — versión 8

Nueva base del proyecto usando la imagen proporcionada como fondo principal.

## Incluye

- La imagen subida como `assets/campo-fondo.jpg`.
- Destellos animados de estrellas.
- Luciérnagas / destellos sobre el campo.
- Movimiento sutil del fondo para simular viento sin deformar demasiado la imagen.
- Una capa adicional de viento sobre la zona de flores.
- Siete flores interactivas frontales.
- Movimiento suave de las flores.
- Polen al tocar las flores.
- Flores especiales con brillo pulsante.
- Al seleccionar las 7, se abre un segundo escenario.
- Segundo escenario con ramo envuelto.
- Flores del ramo interactivas.
- Polen y mensajes al tocar cada flor del ramo.
- Panel con información de cada flor.

## Estructura

- index.html
- style.css
- script.js
- assets/
  - campo-fondo.jpg

## GitHub

Debes subir todos los archivos conservando la carpeta `assets`.

La imagen se carga con esta ruta:

`assets/campo-fondo.jpg`

Esta versión está pensada como la nueva base estable. Más adelante se pueden sustituir las flores frontales CSS por PNG fotorrealistas sin cambiar el sistema de animación, polen, selección o ramo.
