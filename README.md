# Campo interactivo de lirios — versión 2

Incluye un campo lleno de lirios rojos, blancos y degradados, viento, iluminación, ramo de siete flores, mensajes individuales y polen animado.

## GitHub Pages

Sube `index.html`, `style.css` y `script.js` a la raíz del repositorio. Después entra en **Settings → Pages**, selecciona **Deploy from a branch**, la rama **main** y la carpeta **/(root)**.
