# Campo de lirios para Dani — versión 7

Esta versión cambia la técnica visual: deja de dibujar los lirios principales con formas de Canvas y usa texturas fotográficas PNG extraídas de la imagen de referencia.

- Fondo fotográfico nocturno.
- Lirios interactivos realistas como PNG transparentes.
- Perspectiva mantenida por tamaño y posición.
- Lirios araña y lirios del valle quedan como detalles pequeños del fondo.
- Las 7 flores del ramo son únicamente lirios normales.
- Segundo escenario para un ramo armado y envuelto.
- Polen, movimiento suave y mensajes interactivos.

Importante: sube también la carpeta `assets` a GitHub. La estructura debe conservarse exactamente.
