# Campo de lirios para Dani — versión 4

## Cambios principales

- El campo contiene muchas más flores y pasto.
- El cielo incluye luna, estrellas, Vía Láctea suave y luciérnagas.
- El ramo permanece visible mientras se construye.
- Al tocar una flor especial, esta se corta, desaparece del campo y se coloca dentro del ramo.
- Las siete flores están ajustadas para quedar dentro del envoltorio.
- Todas las flores del campo liberan polen al tocarlas.
- Las flores especiales están marcadas con un brillo pulsante.
- Los mensajes no aparecen mientras se arma el ramo.
- Al completar las siete flores, cada lirio del ramo se puede tocar para abrir su mensaje y liberar polen.
- No utiliza WebGL ni librerías externas.

## Instalación

Reemplaza en GitHub:

- `index.html`
- `style.css`
- `script.js`

Después pulsa **Commit changes**. Si GitHub Pages ya está activado, actualiza la página tras uno o dos minutos.

## Personalizar los mensajes

Busca el arreglo `messages` al inicio de `script.js`.
