# Campo interactivo de lirios — versión 3

Esta versión incluye:

- Campo repleto de lirios rojos, blancos y degradados.
- Movimiento de viento en pasto, tallos y flores.
- Polen al tocar cualquier flor del campo.
- Siete flores especiales con brillo más visible.
- Mensaje únicamente al tocar una flor especial.
- Ramo compacto y proporcionado para teléfono y computadora.
- Sin mensaje automático al finalizar.
- En el ramo, cada flor vuelve a mostrar su propio mensaje y libera polen.
- No usa WebGL ni librerías externas.

## Archivos

- `index.html`
- `style.css`
- `script.js`

## Publicar en GitHub Pages

1. Reemplaza en tu repositorio los tres archivos anteriores.
2. Confirma los cambios con **Commit changes**.
3. En **Settings → Pages**, usa la rama `main` y la carpeta `/(root)`.
4. Espera uno o dos minutos y actualiza la página.

Para cambiar los mensajes, edita el arreglo `messages` al principio de `script.js`.
